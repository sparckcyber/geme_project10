
# GEME 3D STUDIO

Editor tridimensional do GEME PROJECT.

## Recursos planejados

- Viewport 3D
- Câmera orbital
- Criação de objetos
- Seleção de objetos
- Transformações
- Sistema de iluminação
- Materiais
- Importação de modelos
- Exportação de projetos
- Editor de cenários
- Interface adaptada para dispositivos móveis

## Estrutura

O editor será desenvolvido em módulos independentes para facilitar a manutenção e expansão.
