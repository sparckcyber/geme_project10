# GEME PROJECT — 3D Studio

Versão inicial integrada do editor 3D no navegador.

## Recursos
- Three.js viewport, câmera orbital, grid e iluminação
- Criação de cubo, esfera, cilindro, plano, cone e toro
- Hierarquia e seleção
- TransformControls (mover, girar, escala)
- Propriedades de posição, rotação, escala, cor, rugosidade e metallicidade
- Importação GLB/GLTF e OBJ
- Exportação GLB
- Salvar e carregar cena em JSON `.geme.json`
- Modo Play básico
- Layout responsivo para celular

## Publicação
Faça upload do `index.html` na raiz do repositório GitHub e conecte o repositório à Vercel. Bibliotecas Three.js são carregadas por CDN, portanto a primeira abertura exige internet.

## Observações
Esta é uma base de editor; o modo Play ainda é uma alternância de estado, não um sistema completo de gameplay, física, scripting ou compilação de jogos.
